# EchoRPC - Audio Metadata Service

> Servicio de consulta de metadatos de audio con gRPC en Go.

**🇪🇸 Español:** Sistema cliente-servidor en Go vía gRPC para buscar metadatos de pistas de audio (título, duración, tipo, disponibilidad) con Protocol Buffers. Proyecto educativo con arquitectura modular (`servidor`, `modelos`, `servicios`, `cliente`).

**🇺🇸 English:** A Go gRPC client–server system for querying audio-track metadata (title, duration, type, availability) using Protocol Buffers. Educational project with a clean modular layout.

---

**EchoRPC** is a Go-based implementation of a gRPC service designed for managing and querying audio file metadata. This project was developed as part of the **Distributed Systems** course.

## Project Structure

The project is organized into two main modules: `cliente` (client) and `servidor` (server).

- **`servidor/`**: Contains the gRPC server logic.
  - `servicios.proto`: Definition of the service and messages using Protocol Buffers.
  - `vistas/servidor.go`: Server entry point (listens on `localhost:50053`).
  - `servicios/`: Contains business logic for searching and loading audio metadata.
  - `modelos/`: Data structure definitions (MetadataAudio, Responses).
  - `serviciosCancion/`: Code automatically generated by `protoc`.

- **`cliente/`**: Contains the gRPC client implementation.
  - `cliente.go`: Console interface for performing audio searches by title.

## Requirements

- **Go** (version 1.24 or higher recommended).
- **gRPC** installed: `go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest`
- **Protocol Buffers** installed: `go install google.golang.org/protobuf/cmd/protoc-gen-go@latest`

## Regenerate gRPC Code (Optional)

If you make any changes to `servicios.proto`, you can regenerate the Go code by running the following command from the `servidor/` directory:

```bash
protoc --go_out=. --go-grpc_out=. servicios.proto
```

## Setup and Execution

### 1. Start the Server

Navigate to the server's views folder and run the main file:

```bash
cd servidor/vistas
go run servidor.go
```

The server will start and wait for requests on port `50053`.

### 2. Run the Client

In a new terminal window, navigate to the client folder and run:

```bash
cd cliente
go run cliente.go
```

### 3. Usage

Once the client is running, you will be prompted to enter an audio title. The following titles are pre-loaded in the server:

- `Canción 1`
- `Podcast 2`
- `Ruido Blanco 3`
- `Audiolibro 4`
- `Meditación 5`

If the audio is found, the server returns its duration, type, and availability. Otherwise, a 404 error message is displayed.

## Service Definition (Proto)

The gRPC service is defined as follows:

```protobuf
service serviciosCanciones {
  rpc buscarAudio(PeticionDTO) returns (RespuestaMetadataAudioDTO);
}
```

## Tech Stack

- **Language**: Go (Golang)
- **Communication**: gRPC
- **Serialization**: Protocol Buffers (Proto3)
